 root is guaranteed to be the absolute smallest element. The remaining elements are only 
 partially ordered based on a parent-to-child relationship, meaning a parent node is always
 smaller than its children

if u put randomly any element in the PQ, it will sort almost but not exact order, it will do min-heap automatically
and it look like this
    pq.add(8);
    pq.add(3);
    pq.add(5);
    pq.add(1);
    pq.add(7);
    o/p: [1, 3, 5, 8, 7] ------> NOT Sorted, but min-heap

BUT, using this------------->
    while (!pq.isEmpty()) {
        System.out.print(pq.poll() + " ");
    }
    o/p: [1 3 5 7 8] --------> sorted and Min-heap

Why?
    poll() removes the smallest element (the root).
    After each removal, Java re-heapifies the remaining elements.
    Repeating this gives the elements in ascending order.

✅ peek() → Smallest element (O(1))
✅ poll() → Removes the smallest element (O(log n))
