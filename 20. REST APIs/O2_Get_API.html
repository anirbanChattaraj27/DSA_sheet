Customer Orders GET API

A second read-only question, one level harder than the Product Catalog. Same four steps: design it, code it, test it, then reuse the shape for any parent-child GET question.

1Design 2Code 3Test 4Reuse

The question

Build a read-only Order History API for an online store.

  1. GET /api/v1/customers/{customerId}/orders returns that customer's orders, newest first, with pagination.
  2. It accepts optional filters: status, and a date range with from and to. Any combination must work.
  3. GET /api/v1/customers/{customerId}/orders/{orderId} returns one order. An order that belongs to a different customer counts as not found.
  4. The response shows the customer's name and a computed totalAmount (quantity × unit price). It does not show unitPrice.
  5. Use Controller, Service, Repository and DTO layers.

What is new compared to the Product question

  • Nested URL. The orders live under a customer, so the customer id is part of the path.
  • Several optional filters that can be combined in any way, handled with one query.
  • Ownership check. Order 5 must not be readable through customer 1.
  • Computed field and a related entity (customer name) in the DTO.

The foreign key customer_id sits on the order table. In Java the order holds a @ManyToOne reference to its customer.

Class design

  1. ClientGET /customers/1/ordersSends the request
  2. ControllerCustomerOrderControllerHTTP only. Reads path and query values.
  3. ServiceCustomerOrderServiceChecks customer, validates dates, maps to DTO
  4. RepositoryCustomerOrderRepositoryOne filter query, one lookup by id + customer
  5. Databasecustomer_ordersRows

Entities stay below the Service. DTO OrderResponse is what goes up and out. The Service also uses CustomerRepository for the "does this customer exist" check.

CustomerOrder.java
@Entity
@Table(name = "customer_orders")      // "Order" is a reserved word in SQL and JPQL, so use another name
public class CustomerOrder {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "customer_id")
    private Customer customer;

    @Column(nullable = false)
    private String productName;

    private int quantity;

    @Column(nullable = false)
    private BigDecimal unitPrice;

    @Enumerated(EnumType.STRING)      // store the name, not the ordinal number
    @Column(nullable = false)
    private OrderStatus status;

    @Column(nullable = false)
    private LocalDate orderDate;

    protected CustomerOrder() {}

    // getters only: a read-only API needs no setters
    public Long getId() { return id; }
    public Customer getCustomer() { return customer; }
    public String getProductName() { return productName; }
    public int getQuantity() { return quantity; }
    public BigDecimal getUnitPrice() { return unitPrice; }
    public OrderStatus getStatus() { return status; }
    public LocalDate getOrderDate() { return orderDate; }
}

CustomerOrderRepository.java
public interface CustomerOrderRepository extends JpaRepository<CustomerOrder, Long> {

    // One query for every combination of optional filters.
    // "(:x is null or column = :x)" means: skip this filter when the value is null.
    @EntityGraph(attributePaths = "customer")      // load the customer in the same query (avoids N+1)
    @Query("""
            select o from CustomerOrder o
            where o.customer.id = :customerId
              and (:status is null or o.status = :status)
              and (:fromDate is null or o.orderDate >= :fromDate)
              and (:toDate is null or o.orderDate <= :toDate)
            """)
    Page<CustomerOrder> search(@Param("customerId") Long customerId,
                               @Param("status") OrderStatus status,
                               @Param("fromDate") LocalDate fromDate,
                               @Param("toDate") LocalDate toDate,
                               Pageable pageable);

    // Id AND owner in one lookup: an order of another customer simply is not found
    @EntityGraph(attributePaths = "customer")
    Optional<CustomerOrder> findByIdAndCustomerId(Long id, Long customerId);
}

Service

checks + mapping
CustomerOrderService.java
@Service
public class CustomerOrderService {

    private final CustomerOrderRepository orderRepo;
    private final CustomerRepository customerRepo;

    public CustomerOrderService(CustomerOrderRepository orderRepo, CustomerRepository customerRepo) {
        this.orderRepo = orderRepo;
        this.customerRepo = customerRepo;
    }

    @Transactional(readOnly = true)
    public Page<OrderResponse> list(Long customerId, OrderStatus status,
                                    LocalDate fromDate, LocalDate toDate, Pageable pageable) {
        if (fromDate != null && toDate != null && fromDate.isAfter(toDate)) {
            throw new BadRequestException("'from' must not be after 'to'");
        }
        ensureCustomerExists(customerId);
        return orderRepo.search(customerId, status, fromDate, toDate, pageable)
                .map(this::toResponse);
    }

    @Transactional(readOnly = true)
    public OrderResponse getOne(Long customerId, Long orderId) {
        ensureCustomerExists(customerId);
        CustomerOrder o = orderRepo.findByIdAndCustomerId(orderId, customerId)
                .orElseThrow(() -> new ResourceNotFoundException(
                        "Order " + orderId + " not found for customer " + customerId));
        return toResponse(o);
    }

    private void ensureCustomerExists(Long customerId) {
        if (!customerRepo.existsById(customerId)) {
            throw new ResourceNotFoundException("Customer not found with id: " + customerId);
        }
    }

    private OrderResponse toResponse(CustomerOrder o) {
        BigDecimal total = o.getUnitPrice().multiply(BigDecimal.valueOf(o.getQuantity()));
        return new OrderResponse(o.getId(), o.getCustomer().getName(), o.getProductName(),
                o.getQuantity(), total, o.getStatus(), o.getOrderDate());
    }
}

Controller

HTTP only
CustomerOrderController.java
@RestController
@RequestMapping("/api/v1/customers/{customerId}/orders")
public class CustomerOrderController {

    private final CustomerOrderService service;

    public CustomerOrderController(CustomerOrderService service) {
        this.service = service;
    }

    @GetMapping
    public Page<OrderResponse> list(
            @PathVariable Long customerId,
            @RequestParam(required = false) OrderStatus status,
            @RequestParam(name = "from", required = false)
                @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate fromDate,
            @RequestParam(name = "to", required = false)
                @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate toDate,
            @PageableDefault(size = 10, sort = "orderDate", direction = Sort.Direction.DESC) Pageable pageable) {
        return service.list(customerId, status, fromDate, toDate, pageable);
    }

    @GetMapping("/{orderId}")
    public OrderResponse getOne(@PathVariable Long customerId, @PathVariable Long orderId) {
        return service.getOne(customerId, orderId);
    }
}

Global exception handler

turns exceptions into 404 / 400
GlobalExceptionHandler.java
public record ApiError(int status, String message, Instant timestamp) {}

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ApiError> notFound(ResourceNotFoundException ex) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND)
                .body(new ApiError(404, ex.getMessage(), Instant.now()));
    }

    @ExceptionHandler(BadRequestException.class)
    public ResponseEntity<ApiError> badRequest(BadRequestException ex) {
        return ResponseEntity.badRequest()
                .body(new ApiError(400, ex.getMessage(), Instant.now()));
    }

    // Covers an unknown status (?status=abc), a bad date (?from=15-11-2026) and a non-numeric id
    @ExceptionHandler(MethodArgumentTypeMismatchException.class)
    public ResponseEntity<ApiError> badType(MethodArgumentTypeMismatchException ex) {
        return ResponseEntity.badRequest()
                .body(new ApiError(400, "Invalid value for: " + ex.getName(), Instant.now()));
    }
}

Self-check before you say "done"

  • Parent id is in the path, filters are in the query string
  • Single order is looked up by order id and customer id
  • Unknown customer gives 404, no orders gives 200 with an empty list
  • Bad enum, bad date and from after to give 400
  • DTO hides unitPrice and adds totalAmount
  • Customer is fetched with the order (@EntityGraph), not one query per row
  • Money is BigDecimal, never double
  • List is paginated with a default sort

Follow-up questions to expect

Why look up the order by id and customer id together?
Looking up by order id alone would let anyone read another customer's order by guessing ids. This is a classic access-control bug. Returning 404 also avoids confirming that the order exists.
Why 404 for an unknown customer but 200 for a customer with no orders?
A missing customer is a missing resource. An empty list is a valid answer to "which orders match?".
What is the N+1 problem here, and how did you avoid it?
Reading order.getCustomer().getName() on a lazy relation fires one extra query per row. @EntityGraph(attributePaths = "customer") loads the customer in the same query.
What if there are 6 optional filters?
Switch from the is null or query to JPA Specifications or Querydsl, so each filter is a small piece added only when present.
The :x is null trick fails on PostgreSQL. Why?
Some databases cannot infer the type of a null parameter in :x is null. Fixes: cast the parameter in the query, or use Specifications. It works on H2, which is why it is fine for the interview.
Why is the entity not called Order?
ORDER is a reserved word in SQL and JPQL (order by). Use CustomerOrder or set @Table(name = "orders") and avoid the name in JPQL.

Reuse

Any "list the children of a parent, with filters" question is this same shape. Only the pieces below change.

The 6-step recipe for a parent-child GET

  1. Name the parent and child. Put the parent id in the path: /parents/{parentId}/children.
  2. List the filters the question mentions. Each becomes an optional @RequestParam.
  3. Repository: one @Query with (:x is null or ...) per filter, plus findByIdAndParentId for the single lookup.
  4. Service: validate input combinations, check the parent exists, call the repository, map to the DTO.
  5. DTO: drop internal fields, add computed and joined fields.
  6. Handler: map not-found to 404 and bad input to 400. Add @EntityGraph if the DTO touches a lazy relation.

Worked example with a new question

"Get a bank account's transactions, filtered by type and date range, newest first. Debits are shown as negative amounts." Only these pieces change. The service keeps its shape: validate, check the account exists, call the repository, map to the DTO.

Only the parts that change
// Repository
@EntityGraph(attributePaths = "account")
@Query("""
        select t from AccountTransaction t
        where t.account.id = :accountId
          and (:type is null or t.type = :type)
          and (:fromDate is null or t.txnDate >= :fromDate)
          and (:toDate is null or t.txnDate <= :toDate)
        """)
Page<AccountTransaction> search(@Param("accountId") Long accountId,
                                @Param("type") TransactionType type,
                                @Param("fromDate") LocalDate fromDate,
                                @Param("toDate") LocalDate toDate,
                                Pageable pageable);

// DTO
public record TransactionResponse(Long id, TransactionType type,
                                  BigDecimal signedAmount, LocalDate txnDate) {}

// Service: the computed field
private TransactionResponse toResponse(AccountTransaction t) {
    BigDecimal signed = t.getType() == TransactionType.DEBIT
            ? t.getAmount().negate()
            : t.getAmount();
    return new TransactionResponse(t.getId(), t.getType(), signed, t.getTxnDate());
}

// Controller
@GetMapping
public Page<TransactionResponse> list(@PathVariable Long accountId,
        @RequestParam(required = false) TransactionType type,
        @RequestParam(name = "from", required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate fromDate,
        @RequestParam(name = "to", required = false) @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate toDate,
        @PageableDefault(size = 10, sort = "txnDate", direction = Sort.Direction.DESC) Pageable pageable) {
    return service.list(accountId, type, fromDate, toDate, pageable);
}
